A see-through teleprompter that sits right under your webcam, follows your voice and coaches every run. **Now on Windows and macOS.**

## Download
| Your computer | File |
|---|---|
| Windows 10 (2004+) / 11, 64-bit | `GlassPrompter-Setup-<version>.exe` |
| Mac with Apple silicon (M1–M4) | `GlassPrompter-<version>-macOS-arm64.dmg` |
| Intel Mac | `GlassPrompter-<version>-macOS-x86_64.dmg` |

- **Windows:** run the installer. No admin rights are needed. If *"Windows protected your PC"* appears, click **More info → Run anyway**. The installer isn't code-signed yet.
- **macOS:** open the .dmg and drag Glass Prompter to Applications. The first time, right-click it and choose **Open**. On macOS 15+, go to System Settings → Privacy & Security and click **Open Anyway**. Allow the microphone when asked if you use Voice Follow.

## New in 2.0
- **macOS app:** floats above full-screen apps on every Space, uses Control+Option shortcuts (no Accessibility permission needed), and has a menu-bar icon and macOS vibrancy.
- **Aurora Glass design:** a living gradient rim shows state (idle, reading, listening), with new icons and a new app icon. The phone app matches.
- **Faster Voice Follow:** 40 ms audio blocks, smooth gliding scroll instead of line jumps, live latency in ms, a mic picker, and auto-reconnect if your mic drops.
- **Honest privacy badge:** green only when the system really hides the prompter from screen share. On macOS 15+ it tells you to share a window instead of the whole screen.
- **Never lose a script:** daily automatic backups and one-click export to Markdown.

Verify downloads with the `.sha256.txt` file next to each one.
